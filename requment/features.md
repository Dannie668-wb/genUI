# 功能点列表

> AI Agent 点餐系统 — 完整功能清单

---

## 核心功能模块

### F1 — 自然语言理解

| # | 功能点 | 说明 |
|---|--------|------|
| F1-1 | 商品名提取 | 从自然语言中识别商品名称 |
| F1-2 | 数量提取 | 识别购买数量（如"两杯"→ 2） |
| F1-3 | 规格提取 | 识别冰度（去冰/少冰/正常）、糖度（无糖/半糖/正常）等属性 |
| F1-4 | 地址提取 | 从表达中提取配送地址（如"公司"→ 关联记忆补全具体地址） |
| F1-5 | 复杂指令解析 | 支持同一订单多商品、各商品不同规格 |

### F2 — 商家与商品匹配

| # | 功能点 | 说明 |
|---|--------|------|
| F2-1 | 获取用户位置 | 经用户授权获取当前位置 |
| F2-2 | 附近商家搜索 | 调用地图/外卖平台 API 获取附近店铺 |
| F2-3 | 智能推荐店铺 | 综合距离、评分、用户偏好排序推荐 |
| F2-4 | 菜单查询 | 获取指定店铺的商品列表及价格 |
| F2-5 | 商品匹配 | 将用户需求与菜单商品对应 |

### F3 — 生成式 UI

| # | 功能点 | 说明 |
|---|--------|------|
| F3-1 | UI Schema 生成 | 后端 Agent 将商品数据转化为标准 JSON Schema |
| F3-2 | 订单确认卡片 | 展示店铺名、商品列表、价格、配送地址 |
| F3-3 | 商品计数器 | 支持 +/- 调整商品数量 |
| F3-4 | 地址修改入口 | 卡片内触发地址修改流程 |
| F3-5 | 支付按钮 | 卡片内直接发起支付 |
| F3-6 | 动态渲染 | 前端渲染引擎将 Schema 映射为实际 UI 组件，无需发版 |

### F4 — Agent 工具调用

| # | 功能点 | 说明 |
|---|--------|------|
| F4-1 | 工具自动选择 | Agent 根据意图自动决定调用哪个工具 |
| F4-2 | search_nearby_shops | 搜索附近商家工具 |
| F4-3 | get_menu | 获取店铺菜单工具 |
| F4-4 | create_order | 创建订单工具 |
| F4-5 | call_payment | 发起支付工具 |
| F4-6 | 工具链编排 | 多工具顺序调用，前一工具输出作为下一工具输入 |

### F5 — 记忆与个性化

| # | 功能点 | 说明 |
|---|--------|------|
| F5-1 | 短期记忆（会话） | 保存当前会话最近 N 轮上下文 |
| F5-2 | 长期记忆（用户画像） | 持久化用户默认地址、口味偏好、常点品牌 |
| F5-3 | 记忆注入 | 会话开始前将用户画像注入 System Prompt |
| F5-4 | 记忆更新 | 每次交互后异步更新用户画像 |
| F5-5 | 地址补全 | 用户说"公司"时自动关联记忆中的具体地址 |

### F6 — 支付闭环

| # | 功能点 | 说明 |
|---|--------|------|
| F6-1 | 应用内支付 | 无需跳转第三方 App，应用内完成支付 |
| F6-2 | 生物识别验证 | 支持 Face ID / 指纹验证 |
| F6-3 | 支付回调处理 | 支付成功/失败后更新订单状态并通知用户 |
| F6-4 | 订单状态追踪 | 支付后展示订单状态（待接单/配送中/已送达） |

### F7 — 高并发与稳定性

| # | 功能点 | 说明 |
|---|--------|------|
| F7-1 | 实时负载监控 | 监控 QPS、CPU、GPU 使用率 |
| F7-2 | 关键词熔断 | 超高负载时对特定关键词请求降级，返回静态文案 |
| F7-3 | 动态关键词配置 | 熔断关键词列表可通过配置中心动态更新 |
| F7-4 | 限流 | Redis 令牌桶/计数器对接口进行限流 |
| F7-5 | 异步处理 | 用户行为事件异步写入 MQ，不阻塞主流程 |

## 功能优先级（MVP 阶段）

| 优先级 | 功能模块 | 目标 |
|--------|----------|------|
| P0（必须） | F1 自然语言理解 | 跑通核心 Agent 意图识别 |
| P0（必须） | F4 工具调用 | Function Calling 驱动业务流程 |
| P0（必须） | F3 生成式 UI | 对话界面 + 简版确认卡片 |
| P1（重要） | F5 记忆 | 基础用户偏好存储与注入 |
| P1（重要） | F2 商家匹配 | 真实 API 集成（初期可用模拟数据） |
| P1（重要） | F6 支付 | Mock 支付，完成交易闭环 |
| P2（可选） | F7 高并发 | 压测后按需添加熔断/限流 |
